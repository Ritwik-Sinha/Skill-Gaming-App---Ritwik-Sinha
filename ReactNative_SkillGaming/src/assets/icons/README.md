# App icons

Original monochrome icons for the app navigation and game screens. The PNG files
have transparent backgrounds and are tinted by `AppIcon`. Each icon includes
24px, 48px, and 72px variants for React Native's 1×, 2×, and 3× asset selection.
The saved PNG files are the final assets. No generation script, vector drawing,
network request, icon font, or runtime rendering package is required.
