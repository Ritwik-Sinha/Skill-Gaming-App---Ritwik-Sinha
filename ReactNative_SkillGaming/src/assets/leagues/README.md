## Final prompt set

One built-in generation call per tier, using this shared prompt with the corresponding name and description below:

> Use case: stylized-concept. Asset type: one transparent mobile game league rank badge, {name}. Primary request: {description}. Premium realistic 3D metallic gaming rank emblem, front-on orthographic view, bevelled polished layered metal edges, dramatic fine specular highlights, dark recesses, perfectly symmetrical. The bottom of shield is pointed and there are two short narrow hanging ribbon tails beneath it. One isolated badge only centered on a genuinely TRANSPARENT alpha background, no backdrop, no floor, no scene. Square canvas, emblem occupies central 65% width and 85% height, fully visible with padding on every side. No text, no letters, no labels, no crown icon, no watermark. Clean silhouette with subtle tight contact shadow within the object only. Designed to be readable at 100 pixels high.
